# Invitation design

The recipient should feel she has opened a thoughtful personal love letter from Fahim. English copy, affectionate default address "my love", clear choices, and an easy phone experience are the direction.

Use warm blush backgrounds, ivory paper, dark rose actions, soft organic flower or heart details, generous whitespace, elegant serif headings, and readable sans-serif body copy. Native SVG/CSS envelope illustration is appropriate. Use semantic CSS variables for color, space, depth, typography, and motion. Keep decorative graphics behind interactive content.

Required checks: 375px mobile, 768px tablet, and 1440px desktop; no horizontal overflow. Buttons at least 44px touch height, visible keyboard focus, readable contrast, proper form labels, and reduced-motion support. No remains reachable. Success appears only after persistence succeeds. An unconfigured backend carries a discreet, clear design-preview label and cannot pretend to save.

Avoid generic dashboard styling in the romantic recipient experience, heavy looping particle effects, obstructive animations, forced audio, tiny controls, and invented personal photos. The admin dashboard uses the same palette with a practical sidebar and readable data views.
